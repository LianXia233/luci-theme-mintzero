§1 · 卡片透明度专项审查 本次重点

P0 TZ-01 · 嵌套毛玻璃层叠加，等效接近不透明 # 主因

cascade.css L3748–L3778 玻璃选择器组

玻璃底为 rgba(255,255,255,0.72) / rgba(23,30,44,0.72)，每层透光率仅 28%。问题是选择器把容器和被它包住的子孙同时列入，透光率按乘法衰减：

嵌套链（真实 DOM 父子）层数等效不透明度 1−0.28ⁿ效果
.cbi-map › .cbi-section › .cbi-section-node › table（表单页标配）499.4%基本全 opaque
.ifacebox › .ifacebox-head + .ifacebox-body（接口页）397.8%同上
.mz-overview-panel › .mz-info-card / .mz-ring-card292.2%明显发白发实
.mz-net-panel › .mz-net-card292.2%同上
.mz-table-card › .mz-data-table thead th（0.85 蓝头）2~95%表头几乎实色
🛠 修复：只给最外层容器上玻璃底 + backdrop-filter，内层一律 background: transparent; backdrop-filter: none（.cbi-map 本身也不应套底）。

P1 TZ-02 · 四个最大面积 UI 件完全不透明

部件背景规则位置
左侧栏（236px × 全高）surface 实色L161 起
顶栏（全宽 × 56px）background 实色L337 起
页脚surface 实色L380 / L1949
吸底操作栏（sticky bottom，常驻）background 实色L3089 起

壁纸模式对四者无任何覆盖规则，只抬了 z-index（L3690–L3693）。建议给 0.88 玻璃底 + blur（注意同步修 TZ-07 的 z-index）；若决策保持实色，请文档化。

P1 TZ-04 · 接口页防火墙区域色丢失

cascade.css L3799 / L3803 rgba(var(--zone-color-rgb, 128,128,128), …) —— 该变量全仓零定义，全部退化为统一中灰，zone 颜色语义（绿 lan / 红 wan）丢失；且浅/深 alpha 不一致（0.78 vs 0.55）。建议 JS 读取内联色换算后写入变量，或改用 color-mix 方案。

P1 TZ-05 · 三处自相矛盾 / 已失效的透明度规则

  1. 旧 0.86/0.9 规则块已死（L3697–L3728）：被 L3748 起的 0.72 块全覆盖；CHANGELOG 仍宣称"86% 半透明"——文档与代码脱节。
  2. 注释与代码相反（L3869–3872）："Slightly deepen"实际是 × 0.8 调浅。默认 0.45 → 0.36。
  3. 表头 fallback 色值前后不一（L3787–3795）：与实际 --mz-color-primary-rgb 对不上，复制粘贴未同步。

P1 TZ-06 · panel 容器玻璃化只做一半

玻璃组只收了 .mz-net-panel / .mz-overview-panel（L3764–65），而 overview.js 实际生成 7 个 panel 容器——被收的形成双层玻璃，没被收的反而正确。修复：7 个容器统一透明无边框，玻璃只留叶子卡片。

P1 TZ-07 · 壁纸模式下移动端抽屉可能关不上

壁纸模式侧栏/顶栏抬到 z-index: 60（L3690–93），汉堡按钮固定 z-index: 50（L295–300）→ 打开的抽屉把按钮盖住。修复：按钮提到 70，或侧栏抬升改为 45。

P2 TZ-08 ~ TZ-12 · 性能 / 兼容 / 可读性

  • TZ-08 性能：~24 个选择器各带 blur(12px) saturate(1.15) + 全屏 ::before blur，中低端手机滚动掉帧。去嵌套（TZ-01）后自然减少 60%+；再加小屏降级（6px 或纯色 0.92）。
  • TZ-09 Safari：::before（L3679）缺 -webkit-backdrop-filter，旧 Safari 遮罩 blur 失效。补一行。
  • TZ-10 iOS：background-attachment: fixed 在 iOS Safari 被忽略/闪烁。建议改 fixed 背景层。
  • TZ-11 halo：全量 text-shadow（约 L3850 起）影响性能与小字渲染；且 WCAG 对比度不计阴影。建议只保留标题 halo。
  • TZ-12 对比度：.mz-net-header 0.75 半透明 + 白字 + 无 halo，亮壁纸下可能跌破 3:1。

P2 TZ-13 ~ TZ-16 · 壁纸链路问题

  • TZ-13 隐私：new Image() 直连 paugram/uapis 默认带 Referer，暴露路由器内网地址。两处加 img.referrerPolicy = 'no-referrer'。
  • TZ-14 重复：UA 正则 × 2 处、API 地址 × 2 处硬编码（menu-mintzero.js L28/46，sysauth.js L101/113），后者还有个从未调用的 wallpaperSourceUrl()。建议收敛共享模块。
  • TZ-15 默认：ui_random 缺省 true + 配置里没这个键 → 新装即全局壁纸，每页挂第三方请求（含 12s 超时）。默认开/关二选一并文档化。
  • TZ-16 校验：wallpaper.uc 对 overlay/blur 直通，非法值 → calc() 失效 → 遮罩整条丢弃。建议后端 clamp（0–1 / 0–40）。

P1 TZ-17 · 配置与后端漂移：Bing 链路"已死但还在跑"

  • /etc/config/mintzero 与 uci-defaults 写的还是旧 Bing 键（market/cache_ttl/random），新键（ui_random/pc_mode/mobile_mode/…）两处都没写，全靠代码缺省硬撑。
  • rpcd/mintzero 读谁也不写的 mode 键 → 恒走 Bing 分支 → "刷新壁纸缓存"按钮每次触发无人消费的 Bing 下载 + 误导通知（wallpaper.js L153–166 的 else 分支实际不可达）。
  • rpcd ACL 授权了不存在的 mintzero wallpaper 方法。
🛠 修复：uci-defaults/config 改写新键并删废弃键；rpcd 的 Bing 下载删除或重定义语义；ACL 删 wallpaper 方法。

§2 · 其他缺陷

P0 OT-01 · 全站 checkbox / radio 被拉成满宽条

cascade.css L1701（vs L1670）· 同特异度 0,1,1，后者覆盖前者

.cbi-value-field input,   /* ← 把 checkbox 也命中了 */
.cbi-value-field select,
.cbi-value-field textarea { width: 100%; }

几乎所有 LuCI 表单勾选框变成 100% 宽 × 16px 高的满宽色条（L1369 还有一处同样的旧规则）。修复：input:not([type="checkbox"]):not([type="radio"]) 或文末加救济规则。

P0 OT-02 · 导航菜单有"永久不可见"单点故障

#mainmenu { display:none !important } 只有 overview.js initMenu()（defer + 800ms 延迟 + 轮询）加的 .mz-menu-ready 能解开；任何一环失败 → 永久无导航。而 menu-mintzero.js 的 display='' 被 !important 压制、完全无效（误导性代码）。修复：渲染者直接加 ready 类，或加超时保活网。

P1 OT-03 ~ OT-05 · 概览页三连击

  • OT-03：.mz-info-cards/.mz-rings 是 display:flex（L1203–1219），却配了 6+ 处 grid-template-columns !important —— 桌面固定列规则从未生效。
  • OT-04：overview.js L533/537/543 输出的 .mz-ring-info/.mz-ring-title 全仓零 CSS 定义，圆环标题裸奔（CSS 里叫 mz-ring-meta/label）。
  • OT-05：概览标题/空状态硬编码中文（L308/490/492 等），英文界面也显示中文，与"国际化就绪"矛盾。

P1 OT-06 ~ OT-09 · 菜单 / 主题 / 设置逻辑

  • OT-06（需实机验证）：renderMenuLevel 把 tree 当虚拟根 vs renderBreadcrumb 把 tree 当 admin 本体——二者必坏其一（面包屑大概率永不显示）。
  • OT-07：renderModeMenu 的输出被 #modemenu{display:none!important} 永久隐藏——渲染与 CSS 打架，留一删一。
  • OT-08（需实机验证）：header.ut 裸用 theme 变量；若上下文没有 → light/dark 变体选了白选。建议从 media 推导 basename。
  • OT-09：ui_random 表单无 default 显示"关"，实际缺省"开"——设置页与行为相反。

P1 OT-10 ~ OT-13 · 概览采集与脚本架构

  • OT-10：collectCore 按 tables[0/1/2] 位置取数、不校验表头；parseBar 正则 locale 相关 → LuCI 版本/语言一变就错位或归零。
  • OT-11：hideOriginalSections 靠中英标题前缀隐藏原文 + 全局 MutationObserver —— 新语言即原文/面板重复显示，且每次轮询全量扫描。
  • OT-12：两脚本竞态操作 #mainmenu。建议折叠逻辑并入 menu-mintzero 渲染链。
  • OT-13：overview.js（32KB + observers）在所有后台页面加载。建议按 data-page 按需引入。

P2 OT-14 ~ OT-17 · 主题切换 / 死代码 / 上传

  • OT-14：切到"跟随系统"后不挂 matchMedia 监听，要刷新才跟随。
  • OT-16：sysauth.js 死代码（pickWallpaper、wallpaperSourceUrl、永不赋值的 copyright、密码 focus 两次）。
  • OT-17：wallpaper.js mkUpload 死函数；上传逐字节拼 3MB 字符串卡主线程；无 busy 态；服务端无 MIME 校验。

P2 OT-15 · CSS 特异度失控：171 个 !important

3924 行多层覆盖，同一组件定义 2–5 次（.cbi-dropdown ×3、.cbi-value ×3、table.table ×3+、.cbi-tabmenu ×3、.ifacebox ×3、操作栏方向来回覆盖 5+ 次、.mz-sys-grid 列数 !important ×6+）。建议冻结新增、排期按组件收敛。

P2 OT-18 ~ OT-21 · 资源 / 模板 / 文档 / 版本

  • OT-18：logo*.svg 三件套 412KB 实为 base64-PNG 套壳且零引用；favicon.svg 同理。建议删除（路由器闪存寸土寸金）。
  • OT-19：ucode 模板三份实体拷贝 vs 注释声称 symlink —— 改 header 漏同步即分叉。
  • OT-20：README 四处过时（Bing 流程 / dashboard.js / 刷新端点 / 旧选项表）；CHANGELOG "86% 半透明""可可嗨嗨嗨"与代码不符。
  • OT-21：CSS ?v=…f 与 JS ?v=…e 已分叉，且与 CHANGELOG 称的 resource_version 机制不一致。建议抽统一版本常量。

P2 OT-22 ~ OT-26 · 后端 / 工具链

  • OT-22：壁纸后端失败静默吞异常，自定义图不生效零日志。
  • OT-23：登录用户名 entityencode + {{ }} 疑似双重转义。
  • OT-24：注销 fetch 不检查 res.ok 照样 reload。
  • OT-25：rpcd 把 UCI 值直接拼进 shell（root-only，低危，建议白名单）。
  • OT-26：po2lmo.py 的 msgstr[n] 单行解析 bug（译文丢空）+ 与 luci.mk 工具链冗余，建议明确去留并补测试向量。
